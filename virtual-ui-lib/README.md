# 🚀 levonx-lib

An **AI-powered React UI component library** that lets developers use ready-made components or generate custom UI using AI 🤯

---

## 📦 Installation

```bash
npm install levonx-lib
```

---

## ⚡ Usage

```js
import { Button } from "levonx-lib";

function App() {
  return <Button>Click Me 🚀</Button>;
}

export default App;
```

---

## 🔥 Features

* 🤖 AI-generated UI components
* 🎨 Ready-to-use React components
* ⚡ Lightweight and fast
* 🧩 Easy to integrate
* 💡 Prompt-based UI generation
